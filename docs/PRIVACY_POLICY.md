# Política de Privacidad — ETL Multiplataforma UTEM

**Última actualización:** 14 de septiembre de 2026

## 1. Responsable del tratamiento
Esta aplicación es desarrollada como proyecto de título académico por estudiantes de Ingeniería en Informática de la Universidad Tecnológica Metropolitana (UTEM), Chile.

## 2. Propósito de la aplicación
"ETL Multiplataforma UTEM" es una herramienta de uso interno y académico cuyo único fin es extraer métricas públicas de rendimiento desde plataformas de redes sociales (YouTube e Instagram) a través de sus APIs oficiales, para su posterior análisis estadístico en el contexto del Observatorio UX.

## 3. Datos recopilados
La aplicación accede exclusivamente a:
- Métricas públicas de cuentas de redes sociales (impresiones, alcance, interacciones).
- Información básica del perfil público (nombre de usuario, identificador de cuenta).

**No se recopilan** datos personales de usuarios finales, contraseñas, mensajes privados, ni información de terceros.

## 4. Uso de los datos
Los datos extraídos se utilizan únicamente con fines académicos y de investigación dentro del marco del proyecto de título. No se comercializan, comparten ni transfieren a terceros.

## 5. Almacenamiento y seguridad
Los datos se almacenan en una base de datos Azure SQL Database con acceso restringido mediante credenciales autenticadas. Las claves de acceso a las APIs se gestionan mediante variables de entorno protegidas y nunca se exponen en repositorios públicos.

## 6. Eliminación de datos
El usuario propietario de las cuentas conectadas puede solicitar la eliminación completa de los datos almacenados contactando al equipo del proyecto a través del correo electrónico indicado en la configuración de la aplicación.
